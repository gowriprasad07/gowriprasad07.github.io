Scope

What I do

I test web applications, APIs, and the plumbing behind them. Most of my work is hands-on assessment: mapping attack surface, chaining small flaws into real impact, and writing it up so the fix is obvious.

Automated scanners find the easy half. The half that matters — broken access control, business logic you can bend, trust assumptions between services — needs someone sitting with the application until it makes sense. That is the part I enjoy.

Selected work

Sanitised write-ups. Client names and identifying detail removed.

Broken access control in a multi-tenant dashboard

High

Object identifiers were validated for format but never for ownership, letting any authenticated account read records belonging to other tenants. Reported with a minimal reproduction and a suggested authorization check at the data layer.

Password reset token reuse

Medium

Reset tokens stayed valid after use and after a subsequent password change, widening the window for account takeover from a leaked link.

Stored cross-site scripting via profile fields

Low

A display name field escaped output in the main view but not in an admin moderation panel, putting the payload in front of a privileged user.

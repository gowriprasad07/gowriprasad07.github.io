Who I am

I'm a security engineer in Chennai working mostly on web application and API testing. Day to day that means sitting with an application until its logic makes sense, then finding the place where that logic disagrees with itself.

Scanners handle the obvious half. The half I care about is access control, authentication flows, and business logic — the bugs you only find by understanding what the application is for. Nobody has automated that yet.

Right now I'm working through OSCP and rebuilding my Python from the ground up. I got tired of copying payloads I couldn't explain, so I'm learning to write the thing I've been attacking.
